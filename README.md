# Jacob Pallapati — Portfolio

Static site: index.html, styles.css, script.js. No build step.

## Add your headshot
Drop a square photo named `headshot.jpg` next to index.html. The "JP" placeholder disappears automatically.

## Free hosting on GitHub Pages
1. Create a public repo named `jrpallapati.github.io` on GitHub.
2. Upload these files to the repo root (Add file > Upload files) and commit.
3. Visit https://jrpallapati.github.io within a minute or two.
